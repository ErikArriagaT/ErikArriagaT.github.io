"La memoria del crimen: extracción de evidencia de un volcado RAM"

↓ Descargar Reporte Forense (PDF)

Contexto y Objetivo

El análisis de memoria volátil (RAM) es crítico en investigaciones de cibercrimen, ya que permite extraer artefactos y evidencias que no residen en el disco duro, como conexiones de red activas, procesos maliciosos en ejecución y contraseñas en texto plano.

Objetivo Principal: Analizar el volcado de memoria de un caso práctico (OtterCTF.vmem) relacionado con un presunto cibercriminal utilizando el framework Volatility. La meta fue desarrollar habilidades forenses prácticas para identificar evidencia digital, correlacionar indicadores de compromiso y reconstruir las actividades del usuario.

Herramientas Utilizadas

El análisis se realizó en un entorno local seguro utilizando herramientas de línea de comandos para la inspección profunda de la memoria:

  • Volatility 2.6: Versión standalone para Windows, estándar en la industria para el análisis forense de memoria RAM.
  • Símbolo del Sistema (CMD): Entorno de ejecución utilizando tuberías de comandos (pipes) y findstr para filtrado de cadenas.
  • OSINT / Navegador Web: Verificación de inteligencia de fuentes abiertas para rastreo de carteras de Bitcoin y geolocalización.

Metodología de Adquisición y Hallazgos

El peritaje del archivo OtterCTF.vmem siguió una metodología estructurada de extracción de artefactos, empleando múltiples plugins de Volatility:

  1. Identificación del Perfil: Se utilizó el plugin imageinfo para determinar el perfil del sistema operativo objetivo (Windows 7 SP1 x64) y la marca de tiempo de la captura (2018-08-04 22:34:22 +0300).
  2. Extracción de Credenciales: Mediante hashdump y lsadump, se logró recuperar la contraseña en texto plano del usuario principal (Rick): MortyIsReallyAnotter.
  3. Análisis de Red y Registro: El plugin netscan reveló una conexión activa desde la IP local (192.168.202.131) hacia un servidor remoto malicioso (77.102.199.102:7575). Simultáneamente, con hivelist y printkey, se identificó el nombre del equipo: WIN-LO6FAF3DTFE.
  4. Inspección de Procesos: A través de pslist, se identificaron procesos legítimos como BitTorrent.exe y LunarMS.exe, aislando un proceso anómalo con el PID 3720.
  5. Artefactos de Navegación y Portapapeles: El uso combinado de filescan, dumpfiles y clipboard permitió reconstruir el historial de Chrome, identificando las cuentas de correo rickopicko@mail.com / rickypinky@mail.com y la contraseña M@il_Pr0vid0rs expuesta en el portapapeles.
  6. Volcado de Proceso y Análisis de Cadenas: Se extrajo el espacio de memoria exclusivo del proceso malicioso (PID 3720) utilizando memdump. Mediante la búsqueda de cadenas (strings), se logró recuperar una cartera de criptomonedas (Bitcoin): 1MmpEmebJKqXG8nQv4cjJSmxZQFVVmFo63M.

Conclusiones y Visión Profesional

Este laboratorio demostró contundentemente que el análisis de memoria volátil es una técnica irremplazable en la respuesta a incidentes. Permite materializar evidencias efímeras que un análisis forense de disco duro tradicional pasaría por alto (como credenciales sin cifrar, inyecciones en memoria y conexiones de red en tiempo real).

Como futuro ingeniero en ciberseguridad, esta práctica reafirmó la importancia de la minuciosidad pericial: documentar cada comando ejecutado, correlacionar lógicamente los hallazgos técnicos con el contexto del incidente y preservar celosamente la integridad de la evidencia durante todo el ciclo de vida del análisis.
