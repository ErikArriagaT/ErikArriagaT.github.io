LAB 08 FILE PATH TRAVERSAL

Descripción: Explotación exitosa de una vulnerabilidad de File Path Traversal. Se logró evadir las restricciones de navegación relativa (../) inyectando directamente una ruta absoluta, obteniendo acceso a la raíz del servidor para la extracción de archivos críticos de configuración.

LAB 09 FILE PATH TRAVERSAL

Descripción: Explotación exitosa de Path Traversal evadiendo un filtro de sanitización deficiente. Se inyectaron secuencias anidadas (....//) para obligar al servidor a reconstruir el patrón de salto de directorio tras su limpieza superficial, logrando extraer el archivo /etc/passwd.

LAB 10 FILE PATH TRAVERSAL

Descripción: Explotación exitosa de Path Traversal superando mecanismos de filtrado secuencial. Se empleó la técnica de doble codificación URL (%252e%252e%252f) para ofuscar la carga útil durante la validación de seguridad, aprovechando una decodificación superflua en el servidor para lograr extraer el archivo /etc/passwd.

LAB 11 FILE PATH TRAVERSAL

Descripción:Explotación de un fallo lógico en el control de acceso a archivos. Se logró eludir la validación del directorio base manteniendo intacto el prefijo obligatorio (/var/www/images/) y concatenando secuencias de Path Traversal (../../../etc/passwd), lo que permitió la extracción de archivos críticos del servidor.

LAB 12 FILE PATH TRAVERSAL

Descripción:Explotación de una vulnerabilidad de Path Traversal superando restricciones de extensión de archivo. Se utilizó la inyección de un byte nulo (%00) para satisfacer la validación superficial de la aplicación web (forzando una terminación en .png), mientras se obligaba al sistema operativo a truncar la cadena y procesar la extracción del archivo crítico /etc/passwd.
