"La investigación forense: la huella digital de un cibercriminal"

↓ Descargar Reporte Forense (PDF)

Contexto y Objetivo

El análisis de imágenes forenses requiere plataformas especializadas capaces de procesar grandes volúmenes de datos sin alterar la evidencia subyacente. Este laboratorio se centra en la resolución de un incidente de seguridad utilizando material de referencia estándar de la industria.

Objetivo Principal: Familiarizar al analista con el framework Autopsy para el procesamiento de imágenes forenses, desarrollando habilidades prácticas en la investigación de incidentes. Se busca comprender a profundidad la importancia de la cadena de custodia y aplicar estos conocimientos para resolver un caso práctico real extraído del Computer Forensic Reference Data Sets (CFReDS Hacking Case).

Herramientas Utilizadas

El entorno de auditoría se configuró para garantizar el manejo adecuado de las evidencias digitales segmentadas:

  • Autopsy 4.23.1: Plataforma forense de código abierto para el análisis integral de discos y volúmenes.
  • Visor de Registro Integrado: Módulo de Autopsy empleado para la extracción de claves (hives) de Windows (SOFTWARE, SYSTEM).
  • Material de Evidencia: Imagen forense CFReDS Hacking Case (SCHARDT), provista en formato segmentado.

Metodología de Análisis

Se realizó el peritaje de la imagen SCHARDT aplicando el siguiente flujo de trabajo forense:

  1. Preparación de la Evidencia: Descarga, verificación y consolidación de la imagen forense segmentada (desde SCHARDT.001 hasta SCHARDT.008).
  2. Apertura del Expediente: Creación del caso dentro de Autopsy bajo el identificador oficial INV01UPSLP, configurando los metadatos de la investigación.
  3. Ingesta de Datos: Importación de la imagen como origen de datos tipo "Disk Image or VM File", asegurando el cálculo del Hash MD5 para mantener la integridad pericial.
  4. Auditoría del Registro: Extracción y análisis de las colmenas del Registro de Windows (SOFTWARE y SYSTEM) para reconstruir el perfil del sistema y la información de red.
  5. Inspección de Usuarios: Revisión exhaustiva de los perfiles de usuario alojados en el directorio Documents and Settings, en busca de configuraciones, historiales y documentos incriminatorios.
  6. Identificación de Artefactos: Búsqueda orientada a localizar herramientas maliciosas, binarios sospechosos y rastros de ejecución que confirmaran la actividad del atacante.

Hallazgos Clave de la Investigación

  • ✦ Sistema Operativo Base: Windows XP (5.1, build 2600).
  • ✦ Nombre del Equipo (NetBIOS): N-1A9ODN6ZXK4LQ
  • ✦ Propietario Registrado: Greg Schardt.
  • ✦ Cuenta de Usuario Sospechosa: Mr. Evil
  • ✦ Zona Horaria del Sistema: America/Mexico_City.
  • ✦ Artefactos Relevantes: Identificación del software Ethereal (un sniffer de red heredado, precursor de Wireshark) instalado dentro del perfil del usuario, indicativo de posible interceptación de tráfico.
  • ✦ Integridad: Hash MD5 de la imagen procesado y almacenado correctamente en la base de datos del caso.

Conclusiones y Visión Profesional

Este laboratorio representó una oportunidad invaluable para aplicar técnicas de análisis forense digital en un entorno realista. Logré extraer información crítica directamente de las estructuras internas del Registro de Windows, identificar cuentas de usuario involucradas y correlacionar de manera lógica los artefactos de software (como el sniffer de red) con el escenario del incidente.

Como futuro ingeniero en ciberseguridad, esta práctica reforzó mi comprensión de la rigurosidad pericial. Documentar cada paso, garantizar que los hashes de la evidencia coincidan y utilizar plataformas forenses como Autopsy son competencias vitales para reconstruir fielmente la actividad de un cibercriminal y asegurar que los hallazgos sean admisibles en cualquier proceso judicial o corporativo.
