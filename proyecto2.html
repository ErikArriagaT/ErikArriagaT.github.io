INTRODUCCIÓN

Este proyecto documenta la aplicación práctica de los conocimientos adquiridos durante el segundo parcial del curso de Seguridad Informática. Se adjuntan los archivos, configuraciones y evidencias necesarias comprimidas en un archivo ZIP para su revisión detallada.

CONTENIDO DEL PROYECTO

El archivo comprimido incluye los siguientes elementos desarrollados durante las prácticas:

  • Documentación técnica de los laboratorios.
  • Scripts y configuraciones utilizadas.
  • Evidencias de explotación de vulnerabilidades (ej. Path Traversal).
